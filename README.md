# kinofox
my firefox user.js and userChrome.css config

# user.js:
- disable mozilla accounts (don't have use for it)
- disable shortened address bar urls (i always prefer to have the full length url)
- enable userChrome.css customisation (for userChrome.css)

# userChrome.css
- 8px rounding across most of the Firefox UI (closer to Proton)
- hide the bookmarks star on the address bar (i use raindrop.io for bookmarks)
- removes the empty space between the first tab and the upper left edge
- darkens surfaces while still keeping the colors of nova
- added a custom loading animation that goes around the selected tab outline in the tab bar, disabled firefox's default loading animation, and removed outlines when the animation is taking place.
